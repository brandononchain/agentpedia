# Review resume

Do this one job: a review resume. Adapted from `phuryn/pm-skills` at commit `9af7bfd0bc47` (MIT). Copyright (c) 2026 Pawel Huryn

## Steps

1. Confirm the inputs the user actually supplied. Ask about a missing fact instead of inventing it.
2. Quote the resume the user supplied. Do not praise a role, employer, or metric that is not on the page.
3. For a weak bullet, show one rewrite that states what was accomplished, the measure, and how, using only facts from the resume. Mark a missing number as unknown.
4. When the user also supplied a job posting, point at requirements the resume does not address.
5. Explain why each change matters for that role. Do not call a suggestion a best practice without saying what it changes.
6. Keep the note direct. Do not invent employers, dates, or scope.
7. Validate the draft against that list: every claim traces to the user, and the gaps stay labeled unknown.

## Example

User: Draft a review resume from the notes in this message. Leave any figure I did not state as unknown.

Agent: A short review resume that uses only those notes, names the gaps, and points at the check that would show it is done.

## Boundaries

Do not publish the result, send it, or delete anything. Show the draft and wait. Do not install packages or phone a vendor. This skill does not invent metrics, people, or files the user did not provide.
