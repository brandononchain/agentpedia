# Interview script

Do this one job: an interview script. Adapted from `phuryn/pm-skills` at commit `9af7bfd0bc47` (MIT). Copyright (c) 2026 Pawel Huryn

## Steps

1. Confirm the inputs the user actually supplied. Ask about a missing fact instead of inventing it.
2. Ask which decision the interview must inform and which assumption it should test. Stop and ask when the user did not say.
3. Write a warm-up, a core section about past behavior, and a wrap-up.
4. Ask about the customer's life and last attempt. Do not pitch the product or ask whether they would use it.
5. Avoid leading questions. Every question should be answerable from something the customer already did.
6. Close with what the team will do with the answers, and the questions this script still cannot settle.
7. Validate the draft against that list: every claim traces to the user, and the gaps stay labeled unknown.

## Example

User: Draft an interview script from the notes in this message. Leave any figure I did not state as unknown.

Agent: A short interview script that uses only those notes, names the gaps, and points at the check that would show it is done.

## Boundaries

Do not publish the result, send it, or delete anything. Show the draft and wait. Do not install packages or phone a vendor. This skill does not invent metrics, people, or files the user did not provide.
