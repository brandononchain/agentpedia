# Comment code generate a tutorial

Do this one job: a comment code generate a tutorial. Adapted from `github/awesome-copilot` at commit `f10fdb8b2660` (MIT). Copyright GitHub, Inc.

## Steps

1. Confirm the inputs the user actually supplied. Ask about a missing fact instead of inventing it.
2. Apply standard Python best practices
3. Ensure code follows the PEP 8 style guide
4. Rename unclear variables and functions if needed for clarity
5. Add comments throughout the code
6. Use a beginner-friendly, instructional tone
7. Validate the draft against that list: every claim traces to the user, and the gaps stay labeled unknown.

## Example

User: Draft a comment code generate a tutorial from the notes in this message. Leave any figure I did not state as unknown.

Agent: A short comment code generate a tutorial that uses only those notes, names the gaps, and points at the check that would show it is done.

## Boundaries

Do not publish the result, send it, or delete anything. Show the draft and wait. Do not install packages or phone a vendor. This skill does not invent metrics, people, or files the user did not provide.
