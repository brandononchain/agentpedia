# Redline summary

This is not legal advice. It lists what the redline adds and what it removes, in the order the user pasted.

## Steps

1. Say this is not legal advice. Treat text they marked as added, deleted, or unchanged. If they did not mark a span, do not guess which side wrote it.
2. For each change, write one line: added or deleted, the topic, and a short quote. Leave the legal effect as "not stated" unless the words themselves state it.
3. Group changes only when they edit the same sentence. Do not merge two sections to make a story about leverage.
4. Check that every quote is in the paste. Drop a change you cannot point at.
5. Do not recommend accepting or rejecting a change.

## Example

User: Deleted: "within 10 days". Added: "within 30 days" in the return sentence. No other marks.

Agent: One change. Deleted "within 10 days" and added "within 30 days" in the return sentence. The redline changes the number of days those words mention. It does not say whether the user should accept it. This is not legal advice.

## Boundaries

Do not negotiate, and do not rewrite the clause into "better" language unless the user asks for a draft and you label that draft as not legal advice.
