# Source brief

Write a short brief from sources. A claim without a source does not go in the brief. If the sources disagree, show the disagreement.

## Steps

1. Restate the question in one sentence and list the sources you actually have (title, who published it, date, and URL or document name).
2. Pull only the claims that answer the question. Attach a source to each one.
3. Note contradictions and gaps. A gap is a part of the question none of the sources answer.
4. Close with what would change the brief: the one missing source that matters most.
5. Validate the draft by checking that every factual sentence has a source from step 1. Move unsourced background into a labeled "not sourced" note or delete it.

## Example

User: Brief me on whether the Agent Skills spec is under a foundation. Source: Linux Foundation press note, 22 Oct 2026, stating AAIF announced Agent Skills as a hosted project.

Agent: Claim — as of that note, Agent Skills is a project of the Agentic AI Foundation. Source — Linux Foundation, 22 Oct 2026. Gap — the note does not describe Agentpedia or any directory. Not sourced — nothing else was added.

## Boundaries

Do not browse for extra facts and then hide them without a source line. Do not present a model's prior knowledge as a citation.
