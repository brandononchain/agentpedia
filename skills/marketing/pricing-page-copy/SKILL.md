# Pricing page copy

Write pricing copy from the offer the user actually sells. If a price, a limit, or a plan name is missing, leave a bracketed gap. Do not invent a middle tier to make the page look conventional.

## Steps

1. List the plans the user named, with price, billing period, and who each plan is for.
2. For each plan, write a short who-it-is-for line, the included items the user listed, and the limit that matters.
3. Write the next step (start a trial, talk to sales, or install) only if the user named it.
4. Add a short note for what is not included when the user named an exclusion.
5. Validate the page against the offer. Every price and limit must match the user's numbers. Mark gaps instead of smoothing them over.

## Example

User: Free plan is the public catalog. The paid plan is not defined yet. Next step for free is to clone the repo.

Agent: One plan is written, named Free, price 0, for people who want the linted catalog. Included: the public skills and agents. Next step: clone the repo. The paid plan is a gap, not a fictional Pro tier.

## Boundaries

Do not add "most popular" badges. Do not imply a discount or a guarantee the user did not state.
