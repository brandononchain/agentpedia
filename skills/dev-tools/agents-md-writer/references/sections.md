# Sections this draft uses

[AGENTS.md](https://agents.md/) is the public convention for a repo-level guide that coding agents can read. This shelf does not copy that site's template. A draft here has only these sections, and only with facts taken from the repo the user opened:

1. Purpose. One sentence from the README or the user.
2. Layout. The top-level directories that exist, each with what the user or the tree shows they hold.
3. Commands. The install, build, test, and lint commands copied from the manifest or the README. A command that is not written down is omitted.
4. Conventions. Rules the user pointed at, or that a contributing file states.
5. Boundaries. What the repo's own docs already forbid, plus "do not invent a command that was not found".

If a section has no source, write "not found" under that heading. Do not fill it from another project.
