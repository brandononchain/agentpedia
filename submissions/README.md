# Submissions

Pull requests are the only way to ask for a certificate. There is no form and no account.

- `template/example-skill/` is a lint-clean skill you can copy. It is not published.
- `incoming/<name>/` is where to put a skill when you are not sure which shelf it belongs on. The catalog builder ignores this folder. A maintainer moves an accepted skill into `skills/<category>/<name>/` before it can be Listed.

See [/certify](https://agentpedia.sh/certify) for the steps, and `certs/checks/` for the Verified manifest shape.
